# Predictive Analytics Using Historical Data

## Thiranex Project

### 📌 Project Overview

This project uses historical sales data to build a predictive model for forecasting future sales trends.

The project demonstrates how historical data can be cleaned, analyzed, and used with machine learning to make future predictions.

---

## 🎯 Objectives

- Clean and preprocess historical sales data
- Analyze historical sales trends
- Perform feature engineering
- Build a predictive regression model
- Evaluate model accuracy
- Forecast future sales
- Visualize actual and predicted values
- Identify overall sales trends

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## 📊 Dataset

The project uses 48 months of historical monthly sales data from 2022 to 2025.

The dataset contains:

- Date
- Sales

Additional features are created during preprocessing:

- Month Number
- Year
- Month
- Sin Month
- Cos Month
